MY COURSES INFINITE LOADING - FIX IMPLEMENTATION COMPLETE
================================================================================

ISSUE: When students navigate back to My Courses after enrolling in a course,
       the page can get stuck on infinite loading if the API request hangs.

ROOT CAUSE: Raw fetch() with NO timeout protection.
            If request hangs, loading state never clears.

================================================================================
FIXES IMPLEMENTED
================================================================================

1. TIMEOUT & ABORT PROTECTION
   File: apps/web/src/app/dashboard/student/page.tsx
   
   Changes:
   - Added AbortController for request cancellation
   - Added 30-second timeout
   - Proper cleanup on unmount
   - Guaranteed loading state clears in ALL scenarios
   
   Result: Infinite loading spinner ELIMINATED

2. REACT QUERY CACHE INVALIDATION
   File: apps/web/src/features/student/useEnrollment.ts
   
   Changes:
   - Added ['student', 'courses', orgId] to useEnroll() cache invalidation
   - Added ['student', 'courses', orgId] to usePurchase() cache invalidation
   
   Result: Prepares for future React Query migration
